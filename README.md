# Ozon Reviews Auto Responder

Автоматическая система для ответа на отзывы на Ozon с использованием Claude AI.

## Возможности

- 🤖 Автоматическая загрузка отзывов со страницы Ozon
- 🧠 Генерация ответов через Claude AI
- 📋 Автоматическое заполнение форм ответов
- 🔔 Уведомления о ходе обработки
- ⏸️ Возможность пауз и управления процессом
- 💾 Сохранение конфигурации

## Требования

- Windows 10/11
- Python 3.8+
- Chrome/Chromium браузер
- API ключ Claude (или использование веб-версии)

## Установка

1. **Установите Python** с сайта https://python.org

2. **Клонируйте репозиторий или распакуйте архив**

3. **Установите зависимости**:
```bash
pip install -r requirements.txt
```

## Использование

### Запуск приложения

```bash
python main.py
```

### Пошаговая инструкция

1. **Нажмите "1. Открыть Ozon"**
   - Откроется браузер с вашим аккаунтом Ozon
   - Убедитесь, что вы авторизованы

2. **Нажмите "2. Загрузить отзывы"**
   - Приложение загрузит все отзывы со страницы
   - Будет показано количество найденных отзывов

3. **Нажмите "3. Открыть Claude"**
   - Откроется отдельное окно браузера с Claude
   - Убедитесь, что вы авторизованы

4. **Введите настройки**:
   - **Claude API Key**: Если используете API (оставьте пустым для веб-версии)
   - **Задержка**: Время ожидания ответа (в секундах)
   - Нажмите "Сохранить"

5. **Нажмите "4. Начать автоматизацию"**
   - Программа начнет обработку отзывов по одному
   - Для каждого отзыва:
     - Отзыв копируется в буфер обмена
     - Переключается на Claude
     - Отзыв вставляется в Claude
     - Ожидается ответ
     - Ответ копируется
     - Переключается обратно на Ozon
     - Ответ вставляется в форму
     - Ответ отправляется

6. **Следите за логом**
   - В логе отображаются все операции
   - Вы можете видеть текущий отзыв и ответ

## Конфигурация

Конфигурация сохраняется в файле `config.json`:

```json
{
  "api_key": "ваш-ключ-claude",
  "ozon_url": "https://seller.ozon.ru/app/reviews",
  "claude_url": "https://claude.ai",
  "delay": 3,
  "browser": "chrome"
}
```

## Советы и трюки

1. **Для более надежной работы**:
   - Увеличьте задержку ожидания (5-10 секунд)
   - Убедитесь, что Claude открыт в отдельном окне

2. **Если программа зависает**:
   - Проверьте, что оба браузера активны
   - Переключитесь на Claude окно вручную и нажмите Enter

3. **Для частой обработки**:
   - Используйте Claude API вместо веб-версии
   - Это быстрее и надежнее

## Возможные проблемы

### "Отзывы не загружаются"
- Проверьте, что вы авторизованы на Ozon
- Подождите загрузки страницы (3-5 секунд)
- Попробуйте нажать "Загрузить отзывы" снова

### "Не переключается между окнами"
- Убедитесь, что оба окна браузера открыты
- Попробуйте переключиться вручную Alt+Tab

### "Ответ не вставляется"
- Проверьте, что форма ответа активна (курсор в поле)
- Увеличьте задержку перед вставкой
