# Ozon Reviews Auto Responder

Удобная программа для ответа на отзывы Ozon с помощью Claude прямо в браузере.

## Возможности

- 📋 Загрузка всех отзывов со страницы Ozon
- 💬 Отправка отзывов в Claude (веб-версия)
- 🔄 Автоматическое копирование/вставка
- 📱 Удобный интерфейс для управления
- ⚡ Быстрая обработка отзывов
- 💾 История операций в логе

## Требования

- Windows 10/11
- Python 3.8+
- Chrome/Chromium браузер (автоматически скачивается)

## Установка

1. **Установите Python** с сайта https://python.org

2. **Клонируйте репозиторий или распакуйте архив**

3. **Установите зависимости**:
```bash
pip install -r requirements.txt
```

## Использование

### Запуск приложения

```bash
python main.py
```

### Пошаговая инструкция

**Подготовка:**

1. **Нажмите "1. Открыть Ozon"**
   - Откроется браузер с вашим аккаунтом Ozon
   - Убедитесь, что вы авторизованы

2. **Нажмите "2. Загрузить отзывы"**
   - Приложение загрузит все отзывы со страницы
   - Будет показано количество найденных отзывов
   - Первый отзыв отобразится в окне программы

3. **Нажмите "3. Открыть Claude"**
   - Откроется отдельное окно браузера с Claude.ai
   - Убедитесь, что вы авторизованы

**Обработка отзывов:**

4. **Нажмите "📋 Копировать отзыв"**
   - Текущий отзыв скопирован в буфер обмена

5. **Нажмите "💬 Вставить в Claude"**
   - Программа переключится на Claude
   - Отзыв вставится в поле ввода

6. **В Claude:**
   - Отредактируйте запрос если нужно
   - Нажмите Enter или кнопку отправки
   - Получите ответ от Claude

7. **Скопируйте ответ:**
   - Выделите ответ в Claude (Ctrl+A)
   - Скопируйте (Ctrl+C)
   - Нажмите кнопку "📋 Копировать ответ" в программе

8. **Нажмите "✏️ Вставить в Ozon"**
   - Программа переключится на Ozon
   - Ответ вставится в поле ввода ответа

9. **Нажмите "✓ Отправить"**
   - Ответ отправится
   - Программа перейдет к следующему отзыву

10. **Повторите** пункты 4-9 для всех отзывов

## Конфигурация

Конфигурация сохраняется в файле `config.json`:

```json
{
  "api_key": "ваш-ключ-claude",
  "ozon_url": "https://seller.ozon.ru/app/reviews",
  "claude_url": "https://claude.ai",
  "delay": 3,
  "browser": "chrome"
}
```

## Советы и трюки

1. **Для более надежной работы**:
   - Увеличьте задержку ожидания (5-10 секунд)
   - Убедитесь, что Claude открыт в отдельном окне

2. **Если программа зависает**:
   - Проверьте, что оба браузера активны
   - Переключитесь на Claude окно вручную и нажмите Enter

3. **Для частой обработки**:
   - Используйте Claude API вместо веб-версии
   - Это быстрее и надежнее

## Возможные проблемы

### "Отзывы не загружаются"
- Проверьте, что вы авторизованы на Ozon
- Подождите загрузки страницы (3-5 секунд)
- Попробуйте нажать "Загрузить отзывы" снова

### "Не переключается между окнами"
- Убедитесь, что оба окна браузера открыты
- Попробуйте переключиться вручную Alt+Tab

### "Ответ не вставляется"
- Проверьте, что форма ответа активна (курсор в поле)
- Увеличьте задержку перед вставкой
