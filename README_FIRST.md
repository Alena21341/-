# 🚀 Ozon Reviews Helper - ВЫБОР ВЕРСИИ

## Выберите какую версию использовать:

### ✅ ВАРИАНТ 1: КОНСОЛЬНАЯ ВЕРСИЯ (РЕКОМЕНДУЕТСЯ)
**Файл:** `run_console.bat`

**Плюсы:**
- ✓ Очень простая
- ✓ Точно будет работать
- ✓ Минимум зависимостей
- ✓ Не требует установки GUI

**Как использовать:**
1. **Двойной клик** на `run_console.bat`
2. Выбираете действие из меню (1-5)
3. Открывайте браузеры вручную
4. Копируйте/вставляйте через Ctrl+C/V

```
Главное меню:
1. Открыть Ozon в браузере
2. Открыть Claude в браузере
3. Показать отзыв из буфера
4. Показать ответ из буфера
5. Инструкция
0. Выход
```

---

### 2️⃣ ВАРИАНТ 2: ПРОСТАЯ ВЕРСИЯ С GUI
**Файл:** `start.bat`

**Плюсы:**
- ✓ Графический интерфейс
- ✓ Шаблоны ответов
- ✓ Красивый дизайн

**Минусы:**
- Требует установку tkinter
- На некоторых системах может не работать

**Как использовать:**
1. Двойной клик на `start.bat`
2. Окно приложения откроется
3. Нажимайте кнопки для управления

---

### 3️⃣ ВАРИАНТ 3: ПОЛНАЯ ВЕРСИЯ (СЛОЖНАЯ)
**Файл:** `run.bat` или `run_debug.bat`

**Плюсы:**
- Автоматическая загрузка отзывов
- Полная автоматизация

**Минусы:**
- Требует Selenium + ChromeDriver
- Может не работать на некоторых системах
- Много зависимостей

---

## 🎯 Рекомендация:

**Начните с ВАРИАНТ 1 (консоль)** - это точно будет работать!

Если хотите GUI - попробуйте ВАРИАНТ 2.

---

## 📋 Процесс работы (для всех версий):

```
1. Откройте Ozon в браузере
   ↓
2. Скопируйте отзыв (Ctrl+C)
   ↓
3. Откройте Claude в браузере
   ↓
4. Вставьте отзыв в Claude (Ctrl+V)
   ↓
5. Получите ответ от Claude
   ↓
6. Скопируйте ответ из Claude (Ctrl+C)
   ↓
7. Вернитесь на Ozon
   ↓
8. Вставьте ответ в форму (Ctrl+V)
   ↓
9. Отправьте ✓
```
