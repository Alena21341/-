# Решение проблем

## Программа закрывается / ничего не работает

### Решение 1: Запустить с видимой консолью отладки

**Двойной клик на `run_debug.bat`** вместо обычного `run.bat`

Это покажет все ошибки и поможет понять, что не так.

---

## Частые ошибки

### ❌ "Chrome не найден" или "webdriver-manager ошибка"

**Решение:**
```bash
pip install --upgrade webdriver-manager
pip install --upgrade selenium
```

Затем запустите программу снова.

---

### ❌ "AttributeError" или "ImportError"

**Это означает, что не установлены зависимости.**

**Решение:**
```bash
pip install -r requirements.txt
```

Или запустите **install.bat** еще раз.

---

### ❌ "Отзывы не загружаются"

**Причины:**
1. Вы не авторизованы в Ozon
2. На странице нет отзывов
3. Страница не полностью загрузилась

**Решение:**
1. Откройте браузер (нажмите "1. Открыть Ozon")
2. Дождитесь полной загрузки страницы (~3-5 сек)
3. Убедитесь, что видны отзывы на странице
4. Нажмите "2. Загрузить отзывы"

---

### ❌ "Не переключается между окнами"

**Решение:**
1. Убедитесь, что оба окна браузера открыты
2. Они должны быть ВИДНЫ на экране
3. Попробуйте переключиться вручную через Alt+Tab

---

## Как отправить отчет об ошибке

Если у вас появляется ошибка:

1. **Запустите `run_debug.bat`**
2. **Скопируйте текст ошибки из консоли**
3. **Проверьте что:**
   - Python установлен: `python --version`
   - Зависимости установлены: `pip list | grep selenium`
   - Chrome установлен (в системе)

---

## Быстрая диагностика

**Откройте командную строку в папке проекта и выполните:**

```bash
# Проверить Python
python --version

# Проверить зависимости
pip list

# Попробовать импортировать модули
python -c "from automation import OzonAutomation; print('OK')"
```

Если там будут ошибки - отправьте их текст.

---

## Если все равно не работает

1. **Переинсталляция:**
   ```bash
   pip uninstall -y selenium webdriver-manager pyperclip pyautogui
   pip install -r requirements.txt
   ```

2. **Перезагрузка Windows**

3. **Запуск `run_debug.bat` и отправка сообщений об ошибке**
